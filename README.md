# Distance Calculator

## Description
This calculates the distance between two points using math library and I/O libraries.

## How to Run
1. Open the program.
2. Run the program.
3. Enter the required values.

## Input Needed
- x1
- x2
- y1
- y2

## Sample Output
Example:
- x1: 2
- y1: 3
- x2: 7
- y2: 8

The distance between the two points is: 1.41
